## `1015-5` 조건 (2026-10-16)

- 입력: `data/bags/1015-5`를 `sqlite3 .recover`로 복구한 bag(52.9 s). 0.5 s 간격 105프레임, 마스터는 camera1 color.
- 캘리브: `calibration/20261015` (전달값, mocap link 없음). 테이블이 world z에서 12.3° 기울어 있어, 중력은 측정한 테이블 법선으로 둔다(수평 테이블 가정). 물체는 쓰지 않는다.
- 손 박스: depth + RGB 1차 박스(102/105프레임) → HaMeR → 삼각측량 투영 박스 → HaMeR. 삼각측량 102프레임(4뷰 66, 3뷰 31, 2뷰 5), 잔차 중앙값 10.9 px(p90 24.3).
- β: G1에서 세션 전체 하나로 푼 값. 장갑 두께 0 mm(미측정).
- 카메라별 V1(`fit`): 재투영 5.1–8.2 px, 표면 6.5–6.7 mm. 카메라끼리 손목 일치 25–42 mm.
- 4뷰 V1(`fit4`): IMU 미사용은 위 표 E003. IMU와 90° 넘게 어긋난 17프레임은 t ≈ 6.6–11.6 s(장갑 착용 중), 22 s, 31.8–39.4 s에 있었다. 31.8–39.4 s는 육안으로 HaMeR가 뒤집은 것이 확인됐다(위에서 손등 EMF 송신기가 보이지 않는다). 해결은 E005·E006.
- glove 중력: `imu_raw` 가속도계는 움직이는 동안 중력이 아니다(|a| 최대 12.9 m/s²). 그래서 SDK 융합 자세(`/wuji_glove/right/tf`)의 roll·pitch를 쓴다. 두 값은 프레임 중앙값 1.6°, 정지 시 0.1–3.9° 차이다.
- 캘리브 확인: HaMeR 삼각측량 잔차 10.9 px(`20260824_v2`는 손목+MCP 기준 37–146 px). 테이블 평면은 카메라별로 0.47–1.23°, −7.4…+3.8 mm 안에서 일치한다.
- 촉각: 이 클립에는 물체 접촉이 없다. binary 접촉은 거의 항상 0개(최대 4 taxel)다. 모든 구간에서 pressure p99가 0.30–0.33인데, 이는 무접촉 기준선이다. taxel과 G1 MANO 표면의 거리 중앙값은 5.5 mm(4.7–6.1)다.
- 산출물: `output/1015-5/{scene,segment,keypoints,glovefit,fit,fit4,calib,overlay,tactile}/`, `output/1015-5/{overlay,tactile}.{mp4,gif}`.
- 정정: 같은 날 앞선 기록(SAM3 박스, 96프레임, 재투영 13.2 px, IMU 15.7°)은 대체됐다. 그때의 "테이블 0.6–2.6°, world z ≈ +44 mm"는 틀린 측정이었다.
